# Student Marks Manager

## 📌 Project Overview
Student Marks Manager is a simple, menu-driven Python application used to manage student marks and academic records. It allows users to add student details, calculate total marks, percentages, and grades, and view all student records.

## 🚀 Features
- Add student details.
- Enter marks for three subjects.
- Calculate total marks automatically.
- Calculate percentage.
- Automatically assign grades based on percentage.
- View all student records.
- Simple menu-driven interface.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Concepts:** Lists, Functions, Loops, Conditional Statements, User Input, and Type Conversion.

## ⚙️ How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python main.py
```
